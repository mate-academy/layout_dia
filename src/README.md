# Air — Landing Page

Responsive landing page implemented according to a Figma design. Built with semantic HTML, modular SCSS (BEM), and vanilla JavaScript. Includes pixel-perfect layout, responsive behavior, and basic interactivity.

## 📐 Layout

The page is fully responsive and adapts to the following breakpoints:

- 2560px (large screens)
- 1600px (design base)
- 1280px (desktop)
- 1024px (small desktop)
- 640px (tablet)
- 320px+ (mobile)

## 🚀 Features

- ⚙️ **BEM & SCSS** structure with mixins and variables
- 🎯 **Pixel-perfect** layout from Figma
- 🧭 **Smooth-scroll navigation**
- 📸 **Hero slider** with auto/manual image switching
- 🧠 Reusable card components in "Our Expertise" and "Process"
- 🗂️ Responsive layouts with consistent animations
- ✏️ Contact form with:
  - Placeholder guidance
  - Input validation
  - Empty field check
  - Auto-reset on submit
  - Scroll to top on success
- 🗺️ Footer with live Google Maps link
- ✅ No horizontal scroll on mobile
- 🖼️ Favicon and optimized image assets

## 🧱 Stack

- HTML5
- SCSS (BEM)
- JavaScript (ES6)
- Git
