# Air (formerly Dia) — Creative Agency Landing Page

A responsive landing page for the full-service creative agency **Air**, built from a Figma design using semantic HTML5, SCSS, and BEM methodology.

## Links

- **Live Preview:** [DEMO LINK](https://Makson-Tyrchun>.github.io/layout_dia/)
- **Design Mockup:** [Figma Design](https://www.figma.com/design/7qwsWggv9BAxMi2VPhBuPr/Air--formerly-Dia--?node-id=22904-1525&t=emLflarmNcJT6W9x-0)

## Technologies Used

- **HTML5** (semantic layout)
- **SCSS / Sass** (mixins, variables, modular architecture)
- **CSS Grid & Flexbox** (responsive design from `320px` to `2560px`)
- **BEM** (Block Element Modifier methodology)
- **JavaScript** (navigation menu & interactive UI elements)
- **Parcel / Gulp & Linters** (Stylelint, HTMLHint, ESLint)

## Key Features

- Fully responsive layout adapted for mobile (`320px`), tablet (`640px`), small desktop (`1024px`), and large screens (`1600px` – `2560px`).
- Interactive burger menu for mobile and tablet devices.
- Smooth scrolling navigation across all sections (`About us`, `Services`, `Process`, `Testimonials`, `Contact us`).
- Client-side validation for the contact form with clean submission handling.
- Clickable contact details (phone, Google Maps location, social media links) and smooth hover animations.

## Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com<your_account>/layout_dia.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd layout_dia
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm start
   ```

5. **Run linters to check code style:**
   ```bash
   npm run lint
   ```
