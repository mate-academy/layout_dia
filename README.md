# Dia Landing Page  
[Live Demo](https://mateuszcieplak.github.io/layout_dia/)  

The **Dia Landing Page** is a fully responsive and pixel-perfect landing page implemented based on a Figma design. The project uses semantic HTML5, SCSS with BEM methodology, and features multiple interactive UI elements.

### Key features:
- **Responsive design**: Optimized for 6 breakpoints – from 2560px down to 320px.
- **BEM + SCSS structure**: Clear, modular, and scalable CSS using SCSS with the BEM naming convention.
- **Smooth navigation**: Header and footer menu links scroll to corresponding page sections.
- **Interactive slider**: Positioned absolutely in the hero section with a placeholder image (extendable).
- **Content blocks**:
  - **Strategic Agency**
  - **Who We Are**
  - **Our Expertise**: Cards reused with hover effects.
  - **Process**: Cards lifted with `translateY(-50%)`, include hover scaling and link effects.
  - **Testimonials**: Fixed-width review cards with responsive column layout on mobile.
  - **Vision, Passion, Results**: Includes call-to-action button and background graphics.
  - **Send Us a Message**: Validated contact form with auto-clear and scroll behavior.
  - **Contact Us**
  - **Footer**

### UX/UI details:
- **Consistent animations**: Smooth hover and transition effects across the whole page.
- **Form validation**: Clear input requirements, no empty submission allowed.
- **Scroll behavior**: Smooth scroll, anchors lead to the beginning of each block.
- **Google Maps**: Address link opens Google Maps in a new tab.
- **Message field UX**: Allows user-friendly multi-line input.
- **Favicon included**
- **Mobile-first**: No horizontal scrolling on smaller screens.
- **“Hire Us” and “Apply” buttons** lead to the contact form.
- **Optional Hero Slider**: Can be enhanced using Unsplash images.

### Technologies used:
- HTML5
- SCSS
- BEM methodology
- Git & GitHub
- Figma (design implementation)
- Responsive design principles

### Instructions:
1. Clone the repo and open `index.html` in your browser.
2. Use a local server (e.g., Live Server) for full functionality.
3. Customize the slider or background images if needed.
