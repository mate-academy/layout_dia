# Dia Landing Page

## Project Overview
  Dia is a responsive landing page built using HTML and SCSS. The layout has a semantic structure and includes three main sections: header, main, and footer. The project is designed to support various screen sizes — from mobile phones to large desktops.

## DEMO
You can view the project here: https://IOherhi.github.io/layout_dia/

## Features

Responsive design — the page displays correctly on different devices:

Mobile: from 320px

Tablet: from 640px

Small desktop: 1024px

Desktop: 1280px

Large screens: up to 2560px (design max width — 1600px)

Semantic markup with three main sections: header, main, footer

Use of SCSS for organizing styles and easier maintenance

## Technologies

HTML5

SCSS

Responsive design (media queries)
